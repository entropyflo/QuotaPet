# Changelog

All notable changes to QuotaPet are documented here.

## 0.1.0 — 2026-09-29

First public release.

- Live five-hour and weekly Codex quota data through the local Codex App Server.
- Transparent non-activating floating panel with menu-bar controls.
- Persistent 0.5x and 1x pet sizes, position locking, click-through, all-Spaces support, and launch-at-login control.
- Compact 2D apple quota ring and ten-stage full-size apple artwork.
- Native interactive Liquid Glass on macOS 26+, with a macOS 14–15 fallback.
- Deterministic mock preview modes and unit coverage for JSON-RPC, quota parsing, countdowns, missing data, abnormal values, and reconnect policy.
- No telemetry, remote backend, credential storage, or direct internal ChatGPT HTTP access.
